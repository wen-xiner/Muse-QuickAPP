# CPCC 软著提交操作指引 · 心屿 Muse 青少年心理健康辅助软件 V1.0

> 适用范围：软件著作权登记（普通登记）
> 受理机构：中国版权保护中心（CPCC）· cponline.cpcc.org.cn
> 本指引为操作步骤参考，实际以官网当前流程为准（流程偶有调整）

---

- [ ] 源程序 Word 已生成：`docs/软著材料/Muse源程序_前30页后30页.docx`（60 页 × 50 行，页眉含名称/版本/页码）
- [ ] 说明书 Word 已生成：`docs/软著材料/Muse软件说明书_V1.0.docx`

- [ ] 确认著作权人（建议：个人名义申请，见清单注意事项第 3 条）

---

## 第 1 步 · 注册账号（10 分钟）

1. 打开 https://cponline.cpcc.org.cn
2. 点击「注册」→ 选「个人注册」（如用个人名义申请）
3. 需提供：手机号、身份证号、姓名、邮箱，完成实名认证（人脸/短信验证）
4. 注册成功后登录

> 提示：实名认证是硬性要求；如果此前已注册过直接用。

---

## 第 2 步 · 在线填报申请（30 分钟）

1. 登录后进入「软件著作权登记」→ 选择 **「R11 软件著作权登记申请」**
2. 按以下要点填写：

| 字段 | 填写内容 |
|------|----------|
| 软件全称 | 心屿 Muse 青少年心理健康辅助软件 |
| 软件简称 | 心屿 Muse（可选） |
| 版本号 | V1.0 |
| 开发完成日期 | 2026-07-05（与项目最后一次构建时间一致，勿填未来日期） |
| 首次发表日期 | 2026-07-05（Cloudflare Pages 上线日）；若未公开发表则选「未发表」 |
| 开发方式 | 独立开发 |
| 软件分类 | 应用软件 / 行业应用（教育、心理健康类） |
| 著作权人 | 你的姓名（个人申请）或团队约定主体 |
| 权利取得方式 | 原始取得 |
| 权利范围 | 全部权利 |
| 源程序量 | 约 6000 行（按实际填写，前后各 30 页共 60 页） |
| 运行环境 | 浏览器（Chrome/Edge/Safari 等现代浏览器） |
| 编程语言 | JavaScript / Vue 3 |
| 主要功能 | 情绪日记、AI 智能分析、AI 心理问答、危机预警、呼吸冥想、个性化设置 |

3. 上传附件：
   - 源程序 → 上传生成的 Word（或转 PDF 后上传）
   - 说明书 → 上传生成的 Word（或转 PDF）
   - 按官网要求命名：通常「软件全称-源程序」「软件全称-说明书」
4. 提交后生成申请流水号，记录备查

---

## 第 3 步 · 提交与缴费

| 项目 | 说明 |
|------|------|
| 官费 | **免费**（普通登记不收费；谨防收费的"代办"渠道，官网申请即可） |
| 纸质材料 | 线上提交后，视官网提示是否需要邮寄申请表签章页；若提示免邮寄则无需 |
| 邮寄（如需要） | 申请表签章页 + 身份证明复印件，按官网收件地址邮寄 |

---

## 第 4 步 · 等待审查

| 事项 | 说明 |
|------|------|
| 周期 | 普通登记约 **30-40 个工作日** |
| 进度查询 | 官网登录后在「我的申请」查看状态 |
| 补正 | 若审查员要求补正（常见：格式问题、材料不全），需在 **30 日（以通知为准）** 内补正，逾期视为撤回 |
| 加急 | 如学校/简历有 deadline，可走加急通道（有费用，数百元起，周期 5-15 个工作日不等） |

---

## 第 5 步 · 领证

- 审查通过后发放电子证书（官网可下载），纸质证书按申请时填写的地址邮寄
- 证书上显示：软件名称、版本号、著作权人、登记号（如 2026SRxxxxxxx）
- 拿到登记号后即可用于：简历、作品集、项目申报、赛事加分

---

## 常见驳回/补正原因（提前规避）

| 原因 | 规避方法 |
|------|----------|
| 名称/版本三处不一致（申请表、源程序页眉、说明书封面） | 提交前逐项核对 |
| 源程序页数不足或行数每页少于 50 行 | 已按 60 页×50 行排版 |
| 说明书纯文字无图 | 已嵌入功能截图 |
| 材料中出现真实密钥/敏感信息 | 已核查无残留 |
| 著作权人身份信息与注册不一致 | 用注册账号本人的身份申请 |
