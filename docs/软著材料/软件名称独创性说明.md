# 软件名称独创性说明

**致：中国版权保护中心**

本人/本单位申请登记的软件全称：**心屿 Muse 青少年心理健康辅助软件（版本号：V1.0）**，现就该名称的独创性及与已登记软件的区别说明如下：

## 一、名称由来与含义

本软件名称由"心屿"与"Muse"两部分组成：

- **"心屿"**：取"每个人心中都有一座需要温柔守护的岛屿"之意，寓意本软件以温和、陪伴的方式守护青少年心理健康，是创作性词汇组合，并非行业通用术语；
- **"Muse"**：源自希腊神话中的缪斯女神（灵感与艺术之源泉），象征本软件借助 AI 技术引导用户认识、表达与调节情绪，是产品理念的意象化表达。

软件名称准确反映产品定位——面向青少年的心理健康辅助应用，核心功能包括情绪日记记录、AI 智能分析、AI 心理问答、危机预警与情绪调节训练。名称及界面均未使用他人已注册的特有名称、商标或专属词汇。

## 二、名称通用性与独创性边界

"心理健康""辅助""软件"等为行业通用功能描述词汇，通用术语本身不构成著作权法意义上的"独创性表达"；本软件的独创性体现在源代码实现、AI 算法应用、功能模块设计、危机干预机制与交互体验等具体内容，而非通用名称本身。软件名称中的"心屿""Muse"为自创意象组合，与市场上常见的"情绪记录""心理测试"等命名风格有明显区分。

## 三、与已登记/申请软件的本质区别

本软件并非简单的情绪记录或心理测试工具，其核心独创性体现在以下技术实现与功能架构：

1. **AI 智能分析体系**：调用大语言模型从"优势、改进建议、应对方法"三个维度对用户情绪日记生成个性化分析，并自动识别灾难化思维、非黑即白、过度概括等 8 种常见认知偏差，帮助用户建立健康的思维方式；
2. **自研危机检测双引擎**：采用中英文关键词匹配与正则表达式双重校验，实时识别自杀、自残、霸凌等危险信号，检测到危机内容后自动弹出预警并引导用户一键拨打心理援助热线，区别于一般记录类软件的被动存储功能；
3. **多轮对话摘要压缩机制**：AI 心理问答支持 6 大场景，对话超过 50 轮后自动生成前序摘要并缓存复用，在控制成本的同时保持长对话上下文连贯；
4. **隐私优先的本地数据架构**：全部情绪数据存储于本地设备，采用多账户前缀隔离，AI 请求经安全代理转发（访问令牌校验 + IP 速率限制），服务端不保存任何用户日记与对话内容；
5. **情绪调节训练模块**：内置 4 种参数化呼吸练习（4-7-8 放松法、盒式呼吸等）与正念冥想语音引导，配合呼吸动画与震动反馈；
6. **个性化视觉系统**：亮色/暗黑双主题、6 种可切换背景与毛玻璃设计系统，通过 CSS 自定义属性全局切换，为青少年群体提供舒适的使用体验。

以上功能模块、算法应用与交互设计均为独立开发，与他人的"检测""记录""测试"类通用软件在技术路线与功能架构上存在本质区别。
